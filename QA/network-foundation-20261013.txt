Decision:
Reuse the bounded async HTTP request wrapper and its regression tests for
future lobby/account APIs. Adapt the HTTPS base-URL validation without a
default endpoint. No identities, tokens, saved games or server address copied.
TechFounder cooperative state polls every 2.5 seconds (project) / 5 seconds
(social). This is not a real-time action-game replication implementation.
Do not reuse that polling loop for Brainrot movement or explosions.
Authentication/save logic needs a separate security and child-data review;
it has not been ported. Client-authoritative saves must not grant PvP rewards.
