# Brainrot Planet.io 0.6.6

Взрывы Бомбардиро получили отдельный звук при попадании. Версия также включает новые цельные плавники Тралалеро и исправление победы при нулевом количестве жизней из проверенной точки 0.6.5.

## Звук бомб

Прежде у попадания не было собственного звука: звучали высокий сигнал способности и сигнал захвата территории. Теперь оба сигнала исключены для бомб; подсчёт территории, награды и эффекты сохранены.

Добавлены три оригинальных синтезированных звука с широкополосным ударом, низкими и средними резонансами, шумовым раскатом и затуханием. Каждый длится 1,8 секунды. Используются готовые монофонические PCM-файлы 24 кГц, без синтеза и создания объектов при каждом взрыве. Три выделенных источника ограничивают наложение залпа; дальние взрывы тише, предусмотрена стереопанорама.

Взрывные источники учитывают выключение звука, приостанавливаются вместе с игрой и останавливаются при завершении матча или выходе в меню. Громкость устройства не менялась.

## Проверки окончательного APK

На Realme RMX3151 выполнены три отдельные фазы: звук включён — три разных клипа при попаданиях; звук выключен — три события без запуска клипов; звук повторно включён — снова три разных клипа. Ошибок из списка runtime-проверки нет. Журнал подтверждает вызовы воспроизведения и отключения; оценка тембра на реальном динамике остаётся слуховой проверкой пользователя.

Повторная проверка Тралалеро прошла: выбор, портрет, приземление, анимация способности, эффект и прыжок. Среднее шести пятисекундных окон — 58,53 FPS, минимальное окно — 54,71 FPS. Портреты меню дополнительно просмотрены на снимке с телефона.

Непрерывный прогон длился 360,7 секунды в одном процессе: два полных матча и два успешных повтора с новыми приземлениями. В обоих матчах победил Бомбардиро игрока с тремя жизнями, 6,23% и 7,21% территории; победные экраны просмотрены. Runtime-ошибок из списка проверки нет. Среднее 70 пятисекундных игровых окон — 58,77 FPS, минимальное окно — 56,90 FPS.

Память PSS: 316,1 МиБ в начале, максимум 387,6 МиБ, 382,8 МиБ в конце. Эти значения включают прогрев и не доказывают отсутствие утечки; нужен более длительный контроль повторных матчей. Двадцатиминутный тест не считается пройденным. После проверки приложение оставлено в меню, Бомбардиро, средняя сложность; звук включён, вибрация выключена.

Unity-проверки: три звуковых файла импортированы, амплитуды укладываются в заданный запас, проверено затухание по расстоянию; восемь сценариев определения победителя; 104 маршрута по рельефу без провалов; модели, победные позы и кадрирование всех 13 героев. Полная повторная проверка 13 героев на телефоне относится к 0.6.4, а четыре отдельных сценария победы игрока и AI на трёх сложностях — к 0.6.5.

## Защита сборки

Генерация портретов требует графического устройства Unity. Непубличная попытка сборки с `-nographics` дала пустой атлас; окончательный APK пересобран без этого параметра. Добавлена остановка сборки при отсутствии графического устройства и проверка видимых пикселей у каждого из 13 портретов. Атлас окончательной сборки содержит 238 014 байт.

Проверка повторного матча в скрипте теперь сравнивает последнее событие приземления с временной меткой. Подсчёт общего числа событий был ненадёжен из-за вытеснения старых строк кольцевым буфером logcat.

Пакет `com.mikhnevcode.brainrotplanet`, версия 0.6.6, versionCode 43, ARM64, Android API 26 и выше, target API 36. Обновление поверх прежней тестовой установки прошло без удаления приложения. Подпись APK проверена, используется прежний Android Debug key; это не магазинный релиз.

Размер APK — 42 182 629 байт. SHA-256: `c9bb3e11e662a6a25bfd2b43c3a53df1712cf06106d701ec843c42874c66e6d3`. Скачанный обратно по HTTPS APK имеет тот же хеш.

[Исходники 4d0862a](https://github.com/mikhnevcode/brainrot-planet-unity/commit/4d0862a2b7dcb3124be83432d77a37b4b2739503), ветка polish/v0.6.6. Основная ветка и публичная страница 0.6.4 не заменялись.

## До выпуска

Нужны длительный прогон и несколько моделей телефонов, слуховая оценка звука, ручная проверка удобства управления и баланса. Сохраняется задержка первоначальной загрузки матча. Графика и органические формы героев требуют дальнейшей художественной доработки. Для магазина отдельно нужны релизная подпись и проверка требований платформы, включая совместимость с 16 КБ страницами памяти.
