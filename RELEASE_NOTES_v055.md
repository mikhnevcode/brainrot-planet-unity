# Brainrot Planet.io 0.5.5 — три уровня сложности

Дата: 2026-10-12. Unity 6000.2.7f2, Android ARM64, Realme RMX3151.

## Реализация

В меню выбора героя появились варианты «ЛЕГКО», «СРЕДНЕ», «СЛОЖНО». Выбор
сохраняется между запусками игры (PlayerPrefs: `BrainrotAiDifficulty`);
по умолчанию — Medium. Новая сложность применяется к трём ботам при старте
каждого матча, не изменяя физику персонажей, скорость перемещения, правила
закраски и игровые способности игрока.

| Регулируемый параметр | Легко | Средне | Сложно |
| --- | --- | --- | --- |
| Время между решениями | 1.15–1.65 с | 0.45–0.78 с | 0.27–0.43 с |
| Радиус распознавания чужих следов | 17° | 27° | 38° |
| Готовность преследовать след | 30% | 78% | 98% |
| Задержка между способностями | 22–29 с | 14–18 с | 12.5–14.2 с |
| Готовность применить способность при подходящих условиях | 42% | 82% | 98% |
| Планируемые петли | компактные | обычные | более широкие |

Файлы: `Assets/Scripts/AiDifficultyProfile.cs`,
`Assets/Scripts/AiTactics.cs`, `Assets/Scripts/PlanetAI.cs`,
`Assets/Scripts/PlanetGame.cs`. Editor-тест:
`Assets/Editor/AiDifficultySmoke.cs`. Скрипты проверки:
`qa_difficulty_055.py`, `qa_difficulty_persistence_055.py`.

## Проверка Unity

Build exit code 0. Проверка параметров и семи решений:
`AI_DIFFICULTY_SMOKE_PASS levels=3 priorityCases=7 decisionMs=1150/450/270`.

## Реальный Android, Realme RMX3151

Каждый уровень выбран касанием меню, после чего игра работала примерно
45 секунд без управления игроком. Выбранный профиль подтверждён у всех
трёх ботов на каждом уровне.

| Наблюдение | Легко | Средне | Сложно |
| --- | ---: | ---: | ---: |
| Использовано суперспособностей | 1 | 6 | 8 |
| Решений о перехвате чужого следа | 0 | 0 | 17 |
| Захватов территорий ботами | 17 | 33 | 30 |
| Средний FPS | 59.17 | 58.79 | 58.77 |
| Критических ошибок Android | 0 | 0 | 0 |

Эти цифры характеризуют отдельные игровые прогоны, а не гарантированное
количество захватов или попаданий: расстановка и поведение частично
случайны. Усложнение заметно по готовности атаковать, а не по
искусственным бонусам к скорости/жизням.

Отдельно проверено, что выбранный Hard сохранился после перезапуска
и затем Medium сохранился после ещё одного перезапуска. На тестовом
устройстве в результате снова выбран Medium.
