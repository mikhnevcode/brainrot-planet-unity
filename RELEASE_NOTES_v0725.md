# Brainrot Planet.io 0.7.25 — профиль игрока

Дата проверки: 2026-10-15.

## Что изменилось

- При первом запуске один раз показывается понятный экран ввода игрового ника.
- Игру можно продолжить без регистрации с автоматически созданным именем вида `ИГРОК 5181`.
- Ник по-прежнему можно изменить в `Настройки → Игровой ник`.
- Перед входом в сетевой матч видно, под каким именем игрок подключится.
- Добавлены сообщения для пустого, слишком короткого, слишком длинного, зарезервированного и недопустимого ника.
- Имена системных ботов защищены от использования игроком, но остаются допустимыми в сетевом составе матча.
- Добавлена базовая фильтрация русских/английских ругательств и простых цифровых подмен.
- Настоящее имя, адрес почты и Google-аккаунт для гостевой игры не требуются.

## Совместимость сети

Сетевой протокол остаётся версии 9. Сервер 0.7.24 переустанавливать не нужно.
Профиль и подтверждение ника пока хранятся локально в `PlayerPrefs`.

## Проверка

- Unity 6000.2.7f2: сборка Android завершена успешно.
- Встроенные проверки: `PLAYER_RECORDS_SMOKE_PASS cases=24`, остальные gameplay/network smoke — PASS.
- Realme RMX3151: обновление поверх 0.7.24 установлено с сохранением данных.
- Проверено на устройстве: экран первого ввода, экранная клавиатура, сохранение/возврат в меню, отображение ника в сетевом окне.
- После прогрева меню: 59,70 FPS по встроенному пятиисекундному пробнику. Полный матч этой интерфейсной итерацией не переигрывался; игровая механика не менялась.
